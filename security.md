# Security Policy

## Supported versions

Security fixes are generally prioritized for the latest version of the project. If you are using an older build, first reproduce the issue against the latest source and generated extension build.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, discussions, or chat messages.

Use GitHub's private vulnerability reporting for this repository when it is available:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Provide the details requested in the form.

If private vulnerability reporting is unavailable, contact the repository maintainer privately through GitHub and clearly mark the message **Security vulnerability**. Do not disclose the issue publicly until the maintainers have had a reasonable opportunity to investigate and release a fix or mitigation.

## What to include

Please include:

- A clear description of the vulnerability and its potential impact
- The affected version, commit, or component
- Reproduction steps or a minimal proof of concept
- Any required browser, operating system, or extension configuration
- Suggested mitigations, if known

Please remove passwords, tokens, personal data, private chat content, and other secrets from reports and proof-of-concept material.

## Response process

Maintainers will acknowledge reports as soon as practical, investigate the issue, and keep the reporter informed when possible. Valid reports may result in a patch, mitigation guidance, documentation update, or security advisory.

We ask reporters to allow reasonable time for investigation and remediation before making vulnerability details public. We appreciate responsible disclosure and will credit reporters when they request it and it is safe to do so.

## Security and privacy scope

DeepSeek Supervisor V2 is designed to store memory, settings, and skills locally in the browser. Reports involving data exposure, unsafe permissions, extension injection, credential leakage, remote content handling, or unintended network transmission are especially valuable.
