Persistent memory + custom skills for chat.deepseek.com — all data stays on your device.

Chrome / Edge / Brave • Manifest V3 • Svelte 5 • Apache 2.0 • 100% local

🧠 Persistent memory

DeepSeek forgets between sessions — this fixes it. Facts you share are saved locally and injected into every future conversation, with importance levels and full search/edit/export/import.

⚡ Skill system

Markdown files as custom instructions and workflows. Upload or fetch from any URL, toggle per chat — injected only when they change.

Private by design

No telemetry, no servers. Your memories live in your browser's storage and never leave your device except in requests you send to DeepSeek yourself.

Install in 4 steps

  1. Download the .zip from the latest GitHub release (button above)
  2. Optionally verify the SHA-256 checksum (guide linked above)
  3. Extract the zip to a permanent folder
  4. chrome://extensions → enable Developer mode → Load unpacked → select the folder

This landing page is served from the repository's docs/ folder; the "Download" button always points at the newest release.
